# Homepage

Summary: This will be the landing page for Banksy

## Desktop
1. Background for the desktop view of the homepage component will be the image in assets/stonks.png
2. There is a section of the background image that is transparent. In this transparent section there should be these features:
	i. If a user is not logged in, display a message saying "Please log in to be finance guy"
	ii. If a user is logged in we must display a different message: "Welcome to [banksy-logo.png]".
3. Both messages must be vertically centered and fully contained within the transparent section of the background image
4. Messages should use the H1 element

## Mobile
1. Background for the mobile view of the homepage component should be the Lottie animation in assets/budget-animation.json. This should take up about 60-70% of the vertical viewport and be position at the top
2. The remaining 30-40% of the viewport should be a message based on the logged in status of the user:
	i. If a user is not logged in, display a message saying "Please log in to be finance guy"
	ii. If a user is logged in we must display a different message: "Welcome to Banksy, where dreams are dreams".
3. Positioning of messages should be centered below the Lottie animation and use the h1 element. Adjust size of text to eliminate any scrolling

## Functionality
As of this first iteration there is no available functionality of the homepage. It serves only as a landing
